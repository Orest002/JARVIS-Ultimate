## What it is

An ambitious personal-assistant project built to run **100% locally** — no cloud, no data leaving the machine. It listens for a wake word, understands natural language through a local LLM, answers by voice, and can drive tools and automations on the desktop.

## Features

- 🗣️ **Wake-word + voice conversation** — talks and listens hands-free.
- 🧠 **Local language model** — reasoning runs offline on the machine.
- 👁️ **Vision module** — describes what the camera sees (object / scene recognition, OCR).
- 🛠️ **Tool use & automation** — opens apps, runs sandboxed actions, answers system questions.
- 🎛️ **Animated desktop HUD** — an arc-reactor–style interface, not a terminal window.
- 🔒 **Privacy by design** — offline-first, because an assistant that watches you shouldn't phone home.

## Tech stack

`Python` · `Local LLM (Ollama)` · `Speech-to-Text` · `Text-to-Speech` · `Computer Vision / OCR` · `Desktop GUI`

## Why I built it

Two reasons: I wanted to understand how modern AI assistants are actually wired together — speech, reasoning, vision, tool use — and I wanted to prove to myself that all of it can run **privately, on your own hardware**. Building it taught me where these systems are strong and, more interestingly for a security person, where they leak.
